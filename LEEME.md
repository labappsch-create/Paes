# Retopaes – versión de prueba 2

APK para instalar y probar en un celular Android (Android 7 o superior).

- `retopaes-prueba-2-arm64-v8a.apk`: para la gran mayoría de los celulares actuales. **Usa este.**
- `retopaes-prueba-2-armeabi-v7a.apk`: solo para celulares Android antiguos, si el primero no se instala.

Importante: esta versión tiene el identificador definitivo (cl.retopaes.app), así que se instala
como una app nueva. Desinstala antes la versión de prueba 1.

La compra no funciona fuera de Google Play.
