# Retopaes – versión de prueba 3b

Un solo APK que funciona en todos los celulares Android 7 o superior: `retopaes-prueba-3b.apk`.

Si una versión anterior de Retopaes no se deja reemplazar, desinstálala primero.
La compra no funciona fuera de Google Play; usa el código de invitación para probar todo.
