# Retopaes – versión de prueba 3

APK para instalar y probar en un celular Android (Android 7 o superior).

- `retopaes-prueba-3-arm64-v8a.apk`: para la gran mayoría de los celulares actuales. **Usa este.**
- `retopaes-prueba-3-armeabi-v7a.apk`: solo para celulares Android antiguos, si el primero no se instala.

Si tienes instalada la versión de prueba 2, esta se instala encima como actualización y conserva
tu historial. Si todavía tienes la versión de prueba 1, desinstálala.

Novedades: código de invitación (Ajustes o pantalla de pago) y correo de contacto en la política
de privacidad. La compra no funciona fuera de Google Play.
